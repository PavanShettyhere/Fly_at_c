# 🌌 Galactic Explorer: NASA-Style Solar System Simulator

An immersive, high-fidelity browser-based simulation of our solar system, inspired by NASA's "Eyes on the Solar System". Travel through space, explore planets, and discover the wonders of our cosmic neighborhood.

![Galactic Explorer Showcase](https://raw.githubusercontent.com/PavanShettyhere/antigravity-assets/main/galactic_explorer_hero.png)

## 🚀 Key Features

### 1. **High-Fidelity Interactive Cockpit**
- Experience space exploration from within a detailed, futuristic cyberpunk cockpit.
- **Live Telemetry CRT Screens**: Monitor your target, distance, speed, and ETA in real-time.
- **Smooth Animations**: Seamlessly toggle the cockpit view with mechanical unfolding animations.

### 2. **NASA-Inspired Navigation**
- **Mouse Steering**: Intuitive drag-to-rotate navigation (LMB) for professional-grade exploration.
- **Adaptive Orbital Physics**: Realistic momentum-based flight controls with linear and angular inertia.
- **Warp Speed**: Cinematic relativistic effects (blue star-streaks) when approaching light speed.

### 3. **Educational Exploration**
- **Planetary Detail Modals**: Click "Read More" on any celestial body to view a 3D model and detailed sector analysis.
- **Live Data Tracking**: Always know your distance from the Sun or your current target in AU/KM.
- **Explorer's Log**: A persistent checklist that tracks every planet and moon you've visited across sessions.

### 4. **Modern Galactic UI**
- **Universal Glassmorphism**: Premium "frosted glass" UI panels for a sleek, high-tech aesthetic.
- **Cinematic vs Realistic Modes**: Switch between vibrant nebula-filled space and a realistic flat-black void.
- **Adaptive Labels**: Dynamic name tags that scale and fade to reduce visual clutter.

## 🎮 Controls

| Action | Control |
| :--- | :--- |
| **Steer / Look** | Left Click + Drag (Mouse) |
| **Thrust Forward** | `W` or `Shift` |
| **Brake / Reverse** | `S` or `Space` |
| **Yaw Left/Right** | `A` / `D` |
| **Pitch Up/Down** | `W` / `S` |
| **Roll Left/Right** | `Q` / `E` |
| **Toggle Cockpit** | Sidebar Settings |
| **Lock View** | Lock Button (UI) |

## 🛠️ Technology Stack

- **Three.js**: Core 3D rendering and physics engine.
- **Vanilla JavaScript**: Modular logic and state management.
- **HTML5/CSS3**: Glassmorphic UI and responsive layout.
- **LocalStorage API**: For persistent exploration logs and settings.

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/[your-username]/galactic-explorer.git
   ```
2. **Open the project**:
   Simply open `index.html` in any modern web browser or serve it via a local dev server (e.g., Live Server).

3. **Explore**:
   Select a destination from the sidebar and engage thrusters!
